# Interview Quiz

Interview Quiz is a small web app for practicing technical interview questions. Opening the home page loads a random question from the bank. You can browse and search questions, read them as markdown, add and edit entries, archive ones you are done with, and restore them later. Signing in with email and password is required to change the bank.

## Technologies

- **App:** React 19, TypeScript, TanStack Start (SSR), TanStack Router, TanStack Query, TanStack DB, TanStack Form, TanStack Markdown, Valibot
- **UI:** Tailwind CSS v4, shadcn/ui (Base UI), Lucide
- **Backend:** Cloudflare Workers, Cloudflare D1, Drizzle ORM, Better Auth
- **Tooling:** Vite+, pnpm, Wrangler, Vitest
